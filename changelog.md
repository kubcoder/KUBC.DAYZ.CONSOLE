# Журнал версий
## [5.2](https://github.com/kubcoder/KUBC.DAYZ.CONSOLE/releases/tag/5.2)
- Исправлена проверка дублирующихся ников: теперь учитываются все совпадения среди игроков онлайн. При совпадающем нике поиск по имени не выбирает одного из игроков.
- Исправлен поиск игрока: не учитывается регистр никнейма
## [5.1](https://github.com/kubcoder/KUBC.DAYZ.CONSOLE/releases/tag/5.1)
- [#33](https://github.com/kubcoder/KUBC.DAYZ.CONSOLE/issues/33) исправлено задвоение ников игрока в глобальном чате.
## [5.0](https://github.com/kubcoder/KUBC.DAYZ.CONSOLE/releases/tag/5.0)
- Изменен поиск игроков по имени. Если имя игрока дублируется, то игрок не будет найден. Однако если игрок Survivor один на сервере обработка текстовых сообщений от него выполняется в полном объеме.
- Добавлена настройка цвета глобального чата в файле `GlobalChat.json`
- Добавлен класс `KCDateTime` - требуется для работы других наших модов. Тут для унификации
- Добавлен аргумент `c` для команды `heal` позволяющий охлаждать перегретого игрока
## [4.1](https://github.com/kubcoder/KUBC.DAYZ.CONSOLE/releases/tag/4.1)
- Добавлены инструменты отправки сообщений из экземпляра данных текстовой команды (#21 #22).
- Добавлена команда работы с заболеваниями игрока (#24)
- Исправлена команда лечения (#20)
## [4.0](https://github.com/kubcoder/KUBC.DAYZ.CONSOLE/releases/tag/4.0)
Рефакторинг мода с целью добавления поддержки файловой системы Linux. 
Работа с файлами реализуется через базовый класс `KCDirectory`, который реализует методы
- создания иерархии папок. 
- получение имени файла в целевой папке.

Выполнена оптимизация кода для упрощения поддержки и расширения функционала. Обработку чата и команд вынесли в отдельные классы `KCGlChat` и `KCCmd.c`.
Код был избавлен от большинства статических методов и переменных, что позволило улучшить читаемость и поддержку кода.

Добавлен базовый класс извлечение случайных имен, который позволяет извлечь случайные имена из заданного списка с указанием вероятности генерации каждого имени. Этот класс используется в других наших модах.
